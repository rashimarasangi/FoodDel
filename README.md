# 🍴 FoodDel – Online Food Delivery Website

A modern, responsive, and user-friendly **food delivery web application** built using **React.js**, **Vite**, and **React Router DOM**.  
FoodDel allows users to explore a wide variety of dishes, view detailed menus, and place online orders with a smooth and intuitive interface.


## ✨ Key Features

- 🏠 **Home Page** – Showcases hero section with a call to action and a brief introduction.  
- 🍕 **Menu Page** – Displays an extensive menu of dishes across multiple categories.  
- 📱 **Mobile App Section** – Promotes the FoodDel app for better accessibility.  
- 🧾 **Contact Section** – Includes business contact information and support details.  
- 🔐 **User Authentication UI** – Sign-in page layout for user access.  
- ⚡ **Responsive Design** – Optimized for all screen sizes (desktop, tablet, mobile).  


## 🧩 Technologies Used

| Purpose | Technology |
|----------|-------------|
| **Frontend Framework** | React.js |
| **Routing** | React Router DOM |
| **Build Tool** | Vite |
| **Styling** | CSS3 |
| **Linting** | ESLint |
